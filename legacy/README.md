# legacy/

Nothing in this directory runs. It is kept only so the history of how the old
Metabella database reached its shape stays readable.

Before the accounting rewrite, schema changes were applied by hand: ~20 raw
`.sql` files, each paired with a bespoke Node runner that opened a pool and
executed the file. There was no `db:migrate`, no journal covering those files,
and no way to reproduce a database from scratch. That is tolerable for a POS.
It is not tolerable for a general ledger, where a schema that drifts from the
migrations silently corrupts financial data.

The system now has exactly one migration lineage, generated by drizzle-kit into
`migrations/` and applied with `yarn db:migrate`.

- `migrations-old/` — the three drizzle migrations and the hand-written SQL that
  predate the baseline. Superseded by `migrations/0000_*`.
- `runners/` — the one-off Node scripts that applied those SQL files.
- `sql/` — assorted backfill and patch SQL from the same era.

If you need something from here, port it into a real migration. Do not run it.
